# 에버랜드 이용쿠폰 신청 웹앱 — 사용 방법

기술 설치 과정은 `README.md`를 참고하세요. 이 문서는 **배포가 끝난 뒤, 행사를 운영할 때** 보는 사용법입니다.

---

## 1. 링크 두 가지

| 용도 | 링크 | 공유 대상 |
|---|---|---|
| 참가자 신청 페이지 | `.../index.html` | 전체 참가자 (밴드 공지) |
| 관리자 페이지 | `.../admin.html` | 운영진만 (비밀번호: `everland2026`) |

> ⚠️ 관리자 링크는 절대 밴드나 단톡방에 공개로 올리지 마세요. 운영진에게만 개별로 전달하세요.

---

## 2. 행사 전: 쿠폰 종류/정원 등록 + 신청 마감 시각 설정

1. `admin.html` 접속 → 비밀번호 입력
2. "쿠폰 구성" 표 아래 **쿠폰 추가**에서 쿠폰 이름과 정원을 하나씩 입력해 등록
   - 예: 자유이용권(30), 우선탑승권(20), 식음료 쿠폰(50), 굿즈 쿠폰(15)
3. 등록한 쿠폰명·정원을 수정하고 싶으면 표에서 값을 직접 고친 뒤 **저장** 클릭
4. 잘못 만든 쿠폰은 **삭제** 클릭 (이미 접수된 신청 데이터에는 영향 없음)
5. **"신청 마감 시각"** 카드에서 신청 가능한 마지막 날짜/시각을 선택 → **저장**
   - 비워두면 마감 없이 언제든 신청 가능
   - 나중에 마감을 없애고 싶으면 **마감 없음** 버튼 클릭
6. **"참가자당 최대 총인원"** 카드에서 한 명이 입력할 수 있는 총인원의 최대치를 설정 → **저장**
   - 예: 4로 설정하면 총인원에 5 이상을 입력할 경우 신청이 막힘
   - 비워두면 제한 없이 몇 명이든 입력 가능, 나중에 **제한 없음** 버튼으로 해제 가능
7. `index.html`을 새로고침해서 등록한 쿠폰이 잘 보이는지 확인 후 참가자에게 링크 공지

---

## 3. 참가자가 신청하는 방법

1. `index.html` 접속
2. 이름, 총인원(본인 포함) 입력
3. 신청 가능 쿠폰 장수 = 입력한 총인원 수 (예: 3명이면 총 3장)
4. 쿠폰 목록에서 +/− 버튼으로 원하는 쿠폰을 필요한 장수만큼 선택 (같은 쿠폰 중복 선택 가능)
5. 하단에 "선택 X / N" 이 정확히 맞아야 **신청하기** 버튼이 활성화됨
6. 신청 완료 화면에서 접수된 내용 확인

- 특정 쿠폰이 마감되면 해당 항목은 자동으로 "마감" 표시되며 선택할 수 없습니다.
- 신청 중 다른 사람이 마지막 수량을 먼저 가져가면, 오류 메시지로 어떤 쿠폰이 마감됐는지 안내되고 다시 선택하면 됩니다.
- 관리자가 설정한 **신청 마감 시각이 지나면**, 페이지 자체가 "신청이 마감되었습니다" 화면으로 바뀌어 더 이상 신청할 수 없습니다.
- 관리자가 **참가자당 최대 총인원**을 설정해뒀다면, 그 수를 넘는 총인원을 입력할 경우 "OO명까지만 신청 가능합니다" 안내가 뜨고 신청하기 버튼이 비활성화됩니다.
- **같은 이름으로는 중복 신청이 자동으로 막힙니다.** 동명이인이 없다는 전제로 이름만 보고 판단하니, 참가자가 이름을 다르게 입력(오타, 띄어쓰기 등)하면 걸러지지 않을 수 있습니다.
- 참가자가 신청 내용을 스스로 조회하거나 수정하는 기능은 없습니다. 잘못 신청한 경우 운영진에게 문의하도록 안내해주세요.

---

## 4. 신청 마감 후: 결과 확인 및 다운로드

1. `admin.html` 접속
2. "신청 현황" 표에서 이름 / 총인원 / 선택한 쿠폰 / 신청 시각을 실시간으로 확인 가능
3. **CSV로 내보내기** 클릭 → 엑셀 파일로 전체 신청 내역 다운로드
   - 경품 지급, 쿠폰 배부 명단 작성 등에 그대로 활용 가능

## 4-1. 개별 신청 검색·수정·삭제하기

참가자가 잘못 신청했거나 운영진이 대신 정정해야 할 때, 전체를 초기화하지 않고 **해당 신청 한 건만** 고칠 수 있습니다.

- **검색**: "신청 현황" 표 위 검색창에 이름을 입력하면 해당 글자가 포함된 신청만 걸러져 보입니다. 검색어를 지우면 전체 목록으로 돌아갑니다.
- **수정**: 해당 행의 **수정** 버튼 클릭 → 이름, 총인원, 쿠폰별 수량을 직접 고친 뒤 **저장**
  - 쿠폰 수량 합계가 총인원 수와 정확히 같아야 저장됩니다.
  - 수량을 늘렸는데 그 쿠폰이 이미 마감된 상태면 저장이 거부되고 어떤 쿠폰이 문제인지 알려줍니다.
- **삭제**: 해당 행의 **삭제** 버튼 클릭 → 확인 후 삭제되며, 그 신청이 차지하고 있던 쿠폰 수량도 자동으로 반환됩니다.

---

## 5. 중복 신청 확인하기

같은 이름으로는 신청 자체가 자동으로 막힙니다(신청 전 자동 확인 후 "이미 같은 이름으로 신청된 내역이 있어요" 안내). 다만 이름을 다르게 입력하는 경우(오타, 띄어쓰기, 영문/한글 혼용 등)까지는 걸러내지 못하니, 마감 후 CSV에서 한 번 더 이름을 확인해두면 안전합니다.

---

## 6. 다음 행사를 위해 초기화하기

행사가 끝나고 다음 행사를 준비할 때:

1. `admin.html` 접속
2. **전체 초기화** 버튼 클릭 (확인 창 2번 나옴)
3. 모든 신청 내역이 삭제되고, 각 쿠폰의 신청 수량이 0으로 리셋됨
   - 쿠폰 종류/정원 설정 자체는 그대로 유지되므로, 이름·정원만 새로 조정하면 바로 재사용 가능
   - 신청 마감 시각 설정은 초기화되지 않으니, 다음 행사에 맞게 **admin.html에서 다시 조정**해주세요.

> ⚠️ 초기화는 되돌릴 수 없습니다. CSV 다운로드로 백업을 먼저 받아둔 뒤 진행하세요.

## 자주 묻는 상황

**Q. 참가자가 잘못 신청해서 내용을 바꾸고 싶다고 해요.**
A. `admin.html`의 신청 현황표에서 해당 행의 **수정** 버튼으로 이름·총인원·쿠폰 수량을 직접 고쳐서 저장하면 됩니다. 완전히 새로 신청받고 싶다면 **삭제** 후 참가자에게 재신청을 안내해주세요.

**Q. 쿠폰 정원을 행사 중간에 늘려도 되나요?**
A. 됩니다. `admin.html`에서 해당 쿠폰의 정원 숫자만 늘려서 저장하면 바로 참가자 화면에 반영됩니다.

**Q. 신청 마감 시각을 연장하고 싶어요.**
A. `admin.html`의 "신청 마감 시각" 카드에서 날짜/시각을 다시 선택하고 저장하면 바로 반영됩니다.

**Q. 관리자 비밀번호를 바꾸고 싶어요.**
A. `admin.html` 파일 안 `const ADMIN_PASSWORD = 'everland2026';` 부분을 원하는 값으로 바꾼 뒤 GitHub에 다시 커밋하면 됩니다.
